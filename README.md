# LiftIQ — Strength Progression Intelligence

LiftIQ is a fitness analytics platform designed to help recreational lifters understand their strength progression, identify potential plateaus, and review workout trends using transparent analytics and AI-assisted explanations.

## Problem

Strength performance fluctuates between workouts. Inconsistent tracking can make it difficult to determine whether progress has stalled or whether a change is simply normal variation.

## Goals

- Record strength-training workouts.
- Visualize exercise-specific performance trends.
- Identify potential plateaus when sufficient data is available.
- Generate explanations grounded in recorded workout statistics.
- Build and deploy a reproducible, monitored ML application.

## Technology Stack

- Frontend: React and Vite
- Backend: Python and FastAPI
- Database: PostgreSQL
- Analytics: Pandas, NumPy and scikit-learn
- Experiment tracking: MLflow
- Pipeline and data versioning: DVC
- Containerization: Docker
- CI/CD: GitHub Actions
- Cloud: AWS

## MVP Scope

1. Workout logging
2. Strength progression dashboard
3. Potential plateau detection
4. AI-assisted workout summaries

## Evaluation

The project will be evaluated using analytics correctness, alert usefulness, data quality, user activation and retention, API reliability, and deployment reproducibility.

## Validation Plan

Interview recreational lifters before finalizing requirements. Test the MVP with consenting users and report observed results, limitations, and feedback honestly.

## Project Status

Planning and problem validation.

## Disclaimer

LiftIQ provides fitness tracking and performance insights, not medical diagnoses or guaranteed training outcomes.
